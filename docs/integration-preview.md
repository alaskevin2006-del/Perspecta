## 本地运行

后端：`cd backend && DEBATE_MODE=mock npm start`

前端另开终端在根目录：`VITE_API_MODE=live npm run dev`

这里前端 live 只表示连接 API；后端必须明确保持 mock。默认代理到 127.0.0.1:3001。不要载入真实密钥或 live 环境文件。
