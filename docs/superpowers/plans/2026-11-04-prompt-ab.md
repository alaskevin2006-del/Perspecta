# Prompt A/B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans task-by-task.

**Goal:** Preserve and fairly compare fused-natural A and faithful-team-v3 B with one real call each.
**Architecture:** Isolated pure builders, independent protocol validation, frozen public request snapshots, bounded one-shot CLI, immutable raw reports.
**Tech Stack:** Node22 built-ins, existing backend catalog/JSON reader, no new dependency or deployed service.
**Spec:** ../specs/2026-11-04-prompt-ab-design.md

## Global Constraints

- Same topic/roster/speaker order/four rounds/temperature0.8/top_p1/4500 output/45s/64KiB; public input cap60000byte and reservation70000 only in this experiment.
- No credential output, env mutation, automatic retries, main writes, deployment, or attributing causal superiority from one sample.

## Review Focus

- Team B may legally lack A callbacks: an independent valid fixture must pass B and fail A.
- Full source may exceed production cap: preflight both under experimental limits, leave production unchanged.
- Duplicate execution: one persistent lock per variant, second run cannot dispatch.
- Failure still spends tokens: capture safe usage before output validation and preserve raw text.
- Metrics miss humanlike meaning: flags never constitute semantic PASS.
