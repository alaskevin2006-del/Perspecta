# 三轮讨论调整

新提示词要求三轮：首轮提出观点，后两轮回应此前其他角色的具体发言，第三轮至少一次延续第二轮。模型只获取压缩后的有来源观点文本，保留角色边界，不把典型问题作为台词。前后端允许二轮历史记录继续展示，新生成结果必须通过三轮校验，否则返回格式错误。默认 mock 为三轮，不是实际人物观点。

后端为一次模型调用，不支持播放中途加入用户发言。真实生成未测试，交锋质量、时延及 3000 token 输出上限是否足够仍待使用经授权的真实调用评估；三轮结果较长可能触及限制。四位人物均为 AI 模拟，非本人发言。
