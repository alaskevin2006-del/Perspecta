# 前端接入交接（2026-11-04 连续辩论版）

当前整合分支已合入前端、后端、画像分支及队友三轮成果，分支来源和有意适配见 [审计](conversation-integration-audit.md)。四位人物视角已接入，模拟页面已验；真实请求、失败和限制见 [验证报告](conversation-validation-20261104.md)。尚无产品负责人或画像组终验结论。

- 三个路径和响应字段维持原契约。当前页面提交 `{topic,roleIds,rounds:4}`，2–4人分别8/12/16条，按返回顺序播放，使用id/roleId/round/replyTo建立引用。四阶段标题与全部历史、复制文本同步。
- 省略rounds保持两轮，显式3保留三轮，第三轮至少一次回应第二轮；新页面不静默接收错误轮次。完整类型见 `backend/api-contract.d.ts`。
- 用户仅在开始前写议题，不支持中途发送回应。页面明示这一点，暂停/继续/下一位/跳过只是播放控制。
- `VITE_API_MODE=live`表示请求后端；实际mock/live由成功响应头识别，缺失时显示待确认。模型密钥仅在后端，不能使用VITE变量。
- 后端默认3001，Vite默认代理同地址；如改端口，启动时设置`API_PROXY_TARGET`。生产须同源转发`/api`并保留模式头。
- 60秒前端等待、45秒后端超时，不自动POST重试或回退。错误保留议题与嘉宾；400/429/500/502/504已做假上游回归，真实模型结构失败亦已在浏览器验证。
- mock是固定占位，对任意新议题不生成答案；历史候选必须明确标历史，实时失败不能替换为历史成功。
- 页面仍保留暂停、历史展开、总结、关于、重置确认、PNG预览下载、完整复制和16份原图片资源。四位头像由本地ID映射；其他安全HTTPS或本地资产可回退显示。

本机验证不等于公网部署。上线还需部署目标、访问范围、反向代理/持久预算方案、运维及成本上限确认，见部署清单。不得通过重启进程规避会话额度限制。
