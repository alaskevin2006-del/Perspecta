# 张雪峰、杜素娟判断案例与验收

本次在现有画像和表达归纳外，为两位人物各增加两组来源可追溯的判断案例。完整情境、判断、理由、限制及原文位置见 `backend/data/persona-decision-cases.json`；数据是编辑归纳，不是人物原话，仍需画像负责人核验。

张雪峰的案例分别涉及考研动机及志愿填报中的学校、专业、城市与能力匹配。杜素娟的案例分别涉及家长代替子女选择，以及不同性格和能力匹配不同职业环境。每组案例都只支持原有语境，不能把其延伸成对绩点和项目等新问题的真实表态。不是人物本人回答过的议题，生成结果仅能视为模型推演。

运行时每人只传两条精简案例，保留情境、判断和理由线索；原始出处和完整限制留在仓库，不把网页当作指令。提示词要求仅在相关时参考思考方式，不照念案例、不虚构本人原话或经历。三种讨论模式均使用案例；二轮模式的原有典型问题保留，避免改变其既有行为。三、四轮模式不再将来源编号传给模型，但完整 `supportedPositions` 与来源对应关系保留在角色目录。输入限制不变，现有角色组合与长输入预算测试覆盖此变更。

## 需要人工复核

1. 逐条核对原文出处与归纳，特别是例外和条件；原文不能支持的新增判断应标为推演或删除。
2. 对相同议题和参数，比较只给姓名、原画像、增强画像；遮住姓名分别评估人物辨识、观点依据、回应质量和虚构事实。评审应记录具体语句及出处，不能将一句话自然流畅等同人物真实。
3. 至少换一个非升学议题重复检查，案例无关时不应被强行提起；截图中的绩点案例不能作为唯一有效性证据。
4. 检查总结是否把未明确认可的观点归为共识。历史真实结果保留原样。

尚未真实调用模型，尚无 A/B 结果、风格盲测或产品验收。前后端交互、现有轮次及运行时预算限制未因本变更改动；用户中途发言仍需另行实现。
