# 张雪峰、杜素娟判断案例与验收

本次在现有画像和表达归纳外，为两位人物各增加两组来源可追溯的判断案例。完整情境、判断、理由、限制及原文位置见 `backend/data/persona-decision-cases.json`；数据是编辑归纳，不是人物原话，仍需画像负责人核验。

张雪峰的案例分别涉及考研动机及志愿填报中的学校、专业、城市与能力匹配。杜素娟的案例分别涉及家长代替子女选择，以及不同性格和能力匹配不同职业环境。每组案例都只支持原有语境，不能把其延伸成对绩点和项目等新问题的真实表态。不是人物本人回答过的议题，生成结果仅能视为模型推演。

运行时每人只传两条精简案例，保留情境、判断和理由线索；原始出处和完整限制留在仓库，不把网页当作指令。提示词要求仅在相关时参考思考方式，不照念案例、不虚构本人原话或经历。整合版目前仅四轮采用带basis/scope的案例投喂，二/三轮保持73caf61既有行为；这是兼容性适配，与队友原分支三种模式都投喂案例的设计不同。四轮仅投喂观点字符串，但完整 `supportedPositions` 与来源对应关系保留在角色目录，A2实验仍保留完整对象投喂。输入限制不变，现有角色组合与长输入预算测试覆盖此变更。
