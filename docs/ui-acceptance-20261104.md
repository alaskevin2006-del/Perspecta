## 发现并修复

HTML502 经 Vite 代理返回时，页面曾直接显示 `Unexpected token ... is not valid JSON`（18）。先在 `scripts/integration-smoke.mjs` 补回归并得到 RED，再修复 `src/data.ts`：非 JSON/空错误页显示安全中文，成功但非 JSON 的响应显示格式错误，网络 TypeError 显示连接提示，null/非字符串错误消息采用通用提示，目录 null 不再报属性访问异常。保留正常 API message、超时提示、模式头和原接口字段，不新增自动重试或 mock 兜底。

修复后同一 Chrome 页面重新加载，注入同类 HTML502，显示“服务暂时不可用，请重试”（19），问题和嘉宾保留；手动重试一次成功并进入总结（20）。两次故障代理生命周期分别记录请求计数，见机器记录；超长输入未增加计数。
