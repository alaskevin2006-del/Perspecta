## 项目一句话

面向大学生升学、就业与自我发展等现实选择的 **AI 多视角圆桌讨论工具**：输入议题、选择角色，看到不同立场的陈述、交锋与结构化总结，帮助用户澄清选择条件，而非替用户做决定。

## 此次必须做成的闭环

**选题 → 选 2–3 个角色 → 发起讨论 → 阅读两轮观点交锋 → 查看共识、分歧与行动建议。**

- **明天（11/4）上午**：调整生成质量、页面和错误处理；中午冻结产品。

## 立即同步的四项约定

1. **接口锁定**：`GET /api/roles`、`GET /api/topics`、`POST /api/debate`；字段与示例见 `02_API_联调契约.md`。不要临时更名。
2. **角色锁定机制**：首版先用三种虚构立场角色（模板已提供）。若改为真实公众人物的观点画像，只修改角色数据，不修改 API 或前端逻辑。
3. **讨论规模锁定**：默认 3 个角色、2 轮、6 条发言、1 份总结；一轮 AI 调用生成完整结果，前端逐条展示。避免首日实现复杂多 Agent。
4. **分支与集成**：建议 `main`（可演示）、`feat/ui`、`feat/api`、`feat/persona`；修改接口先同步，不由各模块自行决定字段。
